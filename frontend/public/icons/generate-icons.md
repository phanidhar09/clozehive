# Icon Generation

Replace this directory with your actual app icons.

Required files:
- icon-192x192.png  (192×192 px)
- icon-512x512.png  (512×512 px)
- icon-maskable-512x512.png  (512×512 px, safe zone is center 80%)
- apple-touch-icon.png  (180×180 px)

You can generate all sizes from a single 1024×1024 source SVG/PNG using:
- https://maskable.app (for maskable icons)
- https://realfavicongenerator.net (for all platform sizes)
